## 1. 背景

大云雀定位为用户友好型 AI 视频、图片与短剧创作平台。产品参考小云雀的国内创作场景、短剧/智能体能力，以及 Digen 的首页即创作入口、灵感广场、模板同款、多模型聚合和工具闭环。

平台采用登录制。游客只能浏览灵感广场和模板，普通用户由管理员创建后才能使用创作能力。管理员负责用户、配额、供应商、模型、任务和内容管理。

## 2. 产品目标

- 让用户从“看到灵感”到“做同款/生成结果”的路径尽可能短。
- 用户不需要理解模型、供应商和 API 差异，系统自动路由到合适模型。
- 管理员可以统一管理用户配额和不同中转供应商接口。
- 生成结果沉淀为项目，而不是零散历史记录。
- 短剧能力分阶段建设，先实现剧本到分镜再到批量生成和 HTML 导出。

## 3. 非目标

- P0/P1 不做公开注册，所有用户由管理员创建。
- P0/P1 不做在线支付、套餐购买和商业授权流程。
- P0/P1 不做完整专业剪辑器，只做基础项目、生成、广场和模板闭环。
- 不在前台暴露复杂供应商配置，普通用户默认任务导向。

## 4. 用户角色

| 角色 | 权限 |
| --- | --- |
| 游客 | 浏览首页、灵感广场、模板详情；点击创作或做同款时跳转登录。 |
| 普通用户 | 使用图片/视频生成、模板同款、项目管理、发布作品到广场；受配额限制。 |
| 管理员 | 拥有普通用户能力；可管理用户、配额、供应商、模型、任务、模板和广场内容。 |

## 6. 核心用户流程

### 6.1 游客浏览到登录

```text
访问首页
→ 浏览灵感广场/模板
→ 点击做同款或创作
→ 跳转登录页
→ 提示“请联系管理员获取账号”
```

### 6.2 用户生成视频

```text
登录
→ 输入 Prompt 或选择模板
→ 系统估算消耗与预计时间
→ 用户确认生成
→ 扣减配额并创建任务
→ 前端轮询任务状态
→ 结果保存为项目
→ 用户下载、继续编辑或发布到广场
```

### 6.3 管理员配置供应商

```text
进入后台供应商管理
→ 添加 Base URL、API Key、认证方式、能力和配置 JSON
→ 测试连接
→ 添加/绑定模型
→ 设置成本、优先级和降级策略
→ 用户生成时系统自动路由
```

## 7. 模块设计

### 7.1 首页

首页承担创作入口、灵感发现和功能分发，不做纯营销页。

核心区域：

- 标题：“今天想创作什么？”
- Prompt 输入框。
- 快捷入口：生成视频、生成图片、用模板做同款、制作短剧。
- 登录用户显示当前配额和预计消耗。
- 热门模板、灵感广场和工具入口。

### 7.2 灵感广场

灵感广场公开可浏览，服务创作转化。

作品卡片展示：

- 预览图或视频。
- 标题、分类、模型、比例、时长、清晰度。
- Prompt 摘要。
- 做同款、收藏、分享。
- 热度和 Remix 次数。

### 7.3 模板中心

模板是结构化生成入口，而不是简单 Prompt 列表。

模板定义：

- 标题、分类、封面、预览视频。
- 输入槽位：角色图、产品图、Logo、文案、背景、音乐。
- 默认参数：模型、比例、时长、清晰度。
- 默认积分消耗。
- Prompt 模板。

### 7.4 创作空间

创作空间用于承载多轮生成，不把结果当作一次性历史。

项目保存：

- 素材。
- Prompt 历史。
- 参数与模型。
- 生成结果。
- 版本记录。
- 导出记录。

### 7.5 `@素材引用`

上传素材后自动生成 mention 名称，例如 `@角色`、`@产品图`、`@参考视频`、`@音乐`。

用户可以在 Prompt 中写：

```text
让 @角色 在雨夜街头缓慢行走，参考 @参考视频 的镜头运动，保持面部一致。
```

后端解析引用并转为供应商支持的多模态请求。不支持多模态的供应商降级为纯文本增强 Prompt。

### 7.6 图片与视频生成

前台以任务为导向：

- 文生图。
- 图生图。
- 文生视频。
- 图生视频。
- 多素材视频。

高级设置才暴露模型、供应商、分辨率、时长、负面提示词等。

### 7.7 短剧工坊

短剧能力分阶段实现。

MVP 流程：

```text
剧本输入
→ AI 解析角色和场景
→ 生成分镜
→ 批量生成图片
→ 批量图生视频
→ 简单排序预览
→ 导出 HTML
```

高级阶段再加入时间线、BGM、字幕、转场和多轨编辑。

### 7.8 工具箱

工具箱用于承接生成后的二次处理。

优先级：

- 图片超分。
- 视频超分。
- 自动字幕。
- 视频比例转换。
- 插帧。
- TTS 配音。

所有工具结果应能保存回项目。

## 10. 数据边界

- 用户只能访问自己的项目、素材、任务和配额日志。
- 发布到广场的作品对游客可见，但原始项目仍归属作者。
- 管理员可查看全局用户、任务、供应商和模型配置。
- API Key 必须加密存储或至少避免前端明文返回。

## 11. 验收原则

- 用户不需要选择供应商即可完成生成。
- 生成前必须展示预计消耗和剩余额度。
- 所有异步生成统一通过任务状态轮询。
- 供应商失败应记录错误，并按配置尝试降级。
- 生成结果必须能保存为项目。
- 文档、代码和测试进度必须同步。
